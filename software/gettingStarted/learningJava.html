Learning Java

Java is an object oriented programming language that can be used for many purposes. In Team 1100, we use it to program the robot on top of a platform called WPILib. Python and C++ are also options that are used by some other teams, but Java is the most popular in this case.

Resources for Learning Java:

Runestone Academy - A set of consecuitive lessons that are good if you are learning Java for the first time, good for general concepts and learning the language as a whole. It is written in the format of a textbook, but has interactive exercises only possible digitally.

W3Schools - Useful for learning specific concepts related to Java, better if you have a specific thing you want to learn about. This website does have ads which may be a problem with slower computers, in which case uBlock Origin or uBlock Origin Lite (depending on your browser) could help.
