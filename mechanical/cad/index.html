Cad Resources

CAD is used for many purposes in robotics, like designing the robot and making the parts for the robot.

Onshape is the CAD software we use the most. It is browser based, so it can be used even on school chromebooks, assuming the district didn't block it.

FrcDesign.org is a website that contains documentation and resources to help with learning Onshape. Additionally, onshape has onshape learning pathways which can also be used to learn.


If you are a team 1100 member, team specific CAD information can be found on the mechanical slack canvas page.
